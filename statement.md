# Project Title: Aircraft Performance & Flight Path Analyzer

## Problem Statement
Manual calculation of aircraft trajectory parameters and performance metrics is time-consuming and prone to human error during preliminary design phases.

## Scope of the Project
This Java-based application automates aircraft profile management, computes fundamental flight performance metrics using standard equations, and logs flight data using object-oriented principles and Java Collections.

## Target Users
* Undergraduate Aerospace Engineering Students
* Junior Propulsion/Flight Mechanics Analysts

## High-Level Features
1. Aircraft data management (CRUD operations via ArrayLists).
2. Performance calculator module (Thrust-to-weight ratio, range, and endurance estimation).
3. File I/O module to import/export aircraft specifications.
